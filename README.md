# Akıllı Arıza Takip — Hafta 6
Hayrünnisa Sümer | Mobil Programlama

## Çalıştırma
```bash
npm ci
npx expo start --clear
```
Expo Go ile QR kodunu okutun.

## Özellikler
Expo Router Stack, arıza listesi, dinamik `/ariza/[id]` detayı, hatalı ID uyarısı, yeni arıza formu, ortak Context state, arama, uzun basarak silme ve durum güncelleme. TicketCard ve StatusBadge ortak bileşenlerdir. Veriler yeniden başlatıldığında sıfırlanır.

Hafta 5 kaynak kodu App.js içinde korunmuştur. Önceki ekran görüntüleri `hafta5-ekran-goruntuleri.png` dosyasındadır. Hafta 6 ekran görüntüleri ve test sonuçları cihazda doğrulandıktan sonra eklenmelidir.

Kodlama ve dosya yolu düzeltmelerinde ChatGPT desteği alınmıştır.
